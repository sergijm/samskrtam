Сгенерируй квиз по падежному склонению санскритских существительных. Список существительных в конце промпта. Интерфейс в виде простого html файла с вложенным javascript

Для каждого существительного определи тип основы по тематической гласной: -a, -ā, -i, -ī, -u, -ū, -ṛ. Для каждого типа выбери три слова случайным образом — итого не более трёх слов на тип, но слова должны быть максимально разными по значению. Просклоняй каждое выбранное слово по всем восьми падежам (именительный, винительный, творительный, дательный, отложительный, родительный, местный, звательный) в трёх числах (единственное, двойственное, множественное).

Структура вопроса Каждый вопрос строится по следующей схеме:  В вопросе фиксируется одно конкретное слово (основа не меняется внутри вопроса, например всегда dhenu-). Указывается падеж и число, для которых нужно выбрать правильную форму. Правильный ответ — полная словоформа (основа + окончание) для указанного падежа и числа. Три неправильных ответа — другие полные формы той же основы (иного падежа или числа, но не совпадающие с правильным ответом). Например, для вопроса «dhenu-, Отложительный, Ед.ч.» правильный ответ dhenoḥ, неправильные — dhenave (дат.), dhenum (вин.), dhenvā (тв.). Все формы записываются в IAST, шрифт Arial. Краткая тематическая гласная в отображении основы не удваивается (писать dhenu-, не dhenuu-). Вопросы каждый раз перемешиваются случайным образом.  Используй хорошо различимые цвета для бэкграунда и шрифта в вариантах ответов.

Фильтры и парадигмы - первый шаг (до начала квиза) Реализуй предварительную фильтрацию вопросов с множественным выбором по каждому параметру:  по тематической гласной (-a, -ā, -i, -ī, -u, -ū, -ṛ); по числу (единственное, двойственное, множественное); по падежу (все восемь).  Состояние фильтров должно сохраняться в localStorage и восстанавливаться при перезагрузке страницы. Отображай парадигмы для всех выбранных гласных, числа и падежей.
Для каждой гласной и слова - одна таблица (колонки: название падежа, единственное, двойственное, множественное)
Управление сессией Реализуй три кнопки:  Начать заново — запустить новый квиз по текущим фильтрам. Продолжить — возобновить прерванный квиз (прогресс сохраняется в localStorage). Только ошибки — запустить квиз только по вопросам, на которые ранее был дан неверный ответ.

Сохранение данных в localStorage Сохраняй в localStorage:  количество попыток и количество ошибок (глобально, по тематической гласной, по падежу); список ошибочных ответов с указанием слова, падежа, числа, правильного ответа и даты; состояние текущей сессии (для кнопки «Продолжить»).  Добавь кнопку «Очистить данные» для сброса localStorage.

Вкладки интерфейса Реализуй четыре вкладки:  Фильтры — настройка параметров выборки и предпросмотр парадигм для всех выбранных типов основ, чисел и падежей, Квиз — основной экран с вопросами и вариантами ответов.  Статистика — количество попыток и процент верных ответов в разбивке по тематической гласной и по падежу. Ошибки — журнал всех ошибочных ответов из localStorage.  выбранная вкладка должна сохраняться при перезагрузке страницы

Оформление:  Общее цветовое оформление - оранжево черное, Правильный и неправильный ответы выделяй визуально после выбора. Санскритские формы записываются в IAST, шрифт Arial. Кнопки должны реагировать на hover и нажатие
