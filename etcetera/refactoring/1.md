## ЗАДАЧА 2.3 — [АГЕНТ 2: Domain Services]

**Зависит от:** 2.2

**Задача:** Реализовать пересчёт экспоненциального рейтинга в `WordScoreService` и вызывать его при каждом ответе пользователя.

**Входные артефакты:**
- `services/quiz-service/src/.../QuizSessionService.java` (метод `submitAnswer`)
- `WordScoreService` из задачи 2.2
- `services/quiz-service/src/.../SessionQuestionRepository.java`

**Алгоритм расчёта score (строго):**

```
Начальное состояние (запись не существует): score = 0

При первом вызове (score == 0):
  если isCorrect → score = 25
  если !isCorrect → score = 5

При последующих вызовах (score > 0):
  если isCorrect  → score = score + (100 - score) * 0.5
  если !isCorrect → score = score * 0.3

После вычисления:
  score = round5(score)          // округление до ближайшего кратного 5
  score = max(score, 5)          // score всегда >= 5 после первого ответа

Функция round5(x):
  return Math.round(x / 5.0) * 5
```

**Что сделать:**

1. Реализовать `WordScoreService.upsertScore(userId, wordId, lessonId, isCorrect)`:
    - Reactive pipeline: `findByUserIdAndWordIdAndLessonId` → вычислить новый score → `save` (upsert через UNIQUE constraint)
    - Если запись не найдена (`switchIfEmpty`) → создать новую с вычисленным score
    - При конкурентных обновлениях — стратегия: `ON CONFLICT (user_id, word_id, lesson_id) DO UPDATE SET score = EXCLUDED.score, updated_at = NOW()` (добавить `@Query` или использовать нативный upsert через `DatabaseClient`)

2. В `QuizSessionService.submitAnswer(...)` после сохранения `QuizAnswer`:
    - Получить `vocabularyWordId` из `SessionQuestion` (поле `vocabulary_word_id`)
    - Получить `quizId` из `QuizSession` как `lessonId`
    - Вызвать `wordScoreService.upsertScore(userId, wordId, lessonId, isCorrect)` в реактивном pipeline (flatMap)
    - **Только для VOCABULARY квизов** — проверять `quiz_type == VOCABULARY`

3. Unit-тесты для `WordScoreService`:
    - Первый правильный ответ: score = 25
    - Первый неправильный ответ: score = 5
    - Серия правильных ответов: проверить convergence к 100
    - Серия неправильных: проверить degradation
    - Граничный случай: score никогда < 5

**Критерии готовности:**
- `upsertScore` идемпотентен при параллельных вызовах (upsert)
- Реактивный pipeline не блокируется
- Unit-тесты покрывают все ветки алгоритма

**Задача:** Обогатить ответ `GET /api/v1/lessons/{lessonType}` полями прогресса пользователя: `totalWordsOwn` (без подкатегорий) и `learnedWords` (слова со score ≥ 80).

**Паттерн:** Composition — ответ content-service вложен в объект quiz-service, который добавляет поля прогресса.

**Итоговая структура ответа:**

```java
// LessonListResponse (возвращается фронту)
public record LessonListResponse(List<LessonItemDto> lessons) {}

public record LessonItemDto(
    // === Данные от content-service (вложены как есть) ===
    String id,          // quizId
    String slug,
    String titleRu,
    String titleEn,
    String descriptionRu,
    String descriptionEn,

    // === Поля прогресса (только для VOCABULARY) ===

    int learnedWords     // кол-во слов у данного userId со score >= 80

```

**Что сделать:**

1. Эндпоинт `GET /api/v1/lessons/{lessonType}` требует аутентификации → получать `userId` из заголовка `X-User-Id` (проставляется Gateway через `IdentityHeaderFilter`).

   > **Альтернатива (если content-service не поддерживает):** добавить поле `directWordCount` в ответ `/content/quizzes?category=VOCABULARY` на стороне content-service (небольшое изменение — согласовать с Агентом 6).

3. В `WordScoreRepository` добавить запрос:
   ```java

     SELECT COUNT(*) FROM quiz.word_score
   ```

    - Собрать `LessonItemDto` с заполненными `totalWordsOwn` и `learnedWords`
    - Использовать `Flux.fromIterable(...).flatMap(...)` для параллельных запросов

**Критерии готовности:**
- `totalWordsOwn` показывает слова **только** данного урока (без подкатегорий)
- `learnedWords` корректно считает слова со score >= 80 для данного userId
- Для не-VOCABULARY квизов поля `totalWordsOwn = 0`, `learnedWords = 0`
- Интеграционный тест: пользователь отвечает правильно N раз → `learnedWords` увеличивается
