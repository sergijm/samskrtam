# US-META-02 — Найти и исправить ошибку в форме

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `ERROR_CORRECTION` (план)
> Связанные файлы: [quest-types-overview.md, тип №31](../../../services/quest-types-overview.md)

## История

Как продвинутый ученик, я хочу тренироваться находить и исправлять ошибку в неверно образованной словоформе или разборе (а не просто образовывать форму с нуля), чтобы развивать навык вычитки и самопроверки — полезный при собственном письме.

## Сценарий

1. Ученик открывает урок «Найди ошибку: склонения».
2. Система показывает неверную форму (`devasya` вместо ожидаемого instrumental `devena`) вместе с заданием (основа, падеж, число).
3. Ученик исправляет форму; при верном ответе система подтверждает и показывает, в чём была ошибка (перепутан падеж — genitive вместо instrumental).

## Критерии приёмки

- [ ] Применим к любому уже существующему типу с известным правильным ответом — не отдельная генерация данных, а обёртка над существующим `QuestItem`: неверный вариант конструируется из соседнего правильного ответа того же набора (см. `quest-item-model.md §2` — переиспользование `AnswerChecker`).
- [ ] Ошибка всегда правдоподобна (реальная типичная ошибка — соседний падеж/лицо/число), не случайный набор символов.
- [ ] Прогресс по ERROR_CORRECTION версии единицы — отдельный от прогресса по обычной генерации той же единицы (разные навыки: образовать vs проверить).

## Вне рамок

- Ошибки в связном тексте нескольких предложений — отдельная будущая история, требует другого масштаба payload.
