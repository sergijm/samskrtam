# US-META-01 — Сессия смешанного повторения по нескольким типам сразу

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `MIXED_REVIEW` (план)
> Связанные файлы: [quest-item-model.md §4](../../../services/quest-item-model.md)

## История

Как ученик с прогрессом по нескольким типам квестов (склонения, спряжения, лексика), я хочу иметь возможность одной сессией повторить все просроченные (DUE) единицы сразу, независимо от их типа, чтобы не заходить в каждый урок по отдельности только ради контрольного повторения.

## Сценарий

1. Ученик открывает Dashboard и видит общий счётчик «Готово к повторению: 23».
2. Система формирует сессию из DUE-единиц по всем Quest пользователя, отсортированных по просроченности, без ограничения одним типом.
3. Ученик отвечает на вопросы вперемешку (склонение, потом слово, потом сандхи); каждый вопрос показывается в своём типовом UI-компоненте.
4. После сессии — общая сводка и раздельная статистика по типам.

## Критерии приёмки

- [ ] Это не новый тип QuestItem, а новый режим `SessionItemSelector` (см. `quest-item-model.md §4`) — не требует изменений в content-service.
- [ ] Фронтенд должен уметь рендерить вопрос любого типа внутри одной сессии — общий контракт `QuestItem`/`AnswerMode` уже это допускает.
- [ ] Смешанная сессия не создаёт новых Quest — прогресс пишется в те же строки `progress`, что и обычные сессии по одному Quest.

## Вне рамок

- Настройка пользователем весов/приоритетов типов в смешанной сессии — на первую версию не нужна, порядок — по просроченности.
