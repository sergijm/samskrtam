# US-META-03 — Перевод целого предложения с разбором по словам

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `SENTENCE_TRANSLATION` (план)
> Связанные файлы: [quest-types-overview.md, тип №32](../../../services/quest-types-overview.md)

## История

Как ученик, прошедший базовые уроки по морфологии и лексике, я хочу переводить целые предложения из реальных текстов (sangraha-service) с опциональной подсказкой по разбору каждого слова, чтобы применять отдельно выученные формы и слова в связном контексте, а не только изолированно.

## Сценарий

1. Ученик открывает урок «Перевод: простые предложения из [название произведения]».
2. Система показывает предложение целиком (`rāmaḥ vanaṃ gacchati`) и просит ввести перевод свободным текстом.
3. Ученик переводит; система показывает эталонный перевод и, по запросу, разбор по каждому слову (форма, падеж/лицо, роль в предложении) со ссылками на уже пройденные единицы прогресса этих слов/форм.

## Критерии приёмки

- [ ] Материал — только предложения из проанализированных фрагментов sangraha-service, с уже готовым словарным разбором (не генерируется на лету).
- [ ] Проверка перевода не строго формальная (это не сверка с одним эталонным ответом) — используется мягкое сравнение или ручная самооценка учеником («я перевёл правильно/неправильно») в первой версии, а не автоматическая оценка качества перевода.
- [ ] Каждое слово в разборе кликабельно и ведёт к соответствующей единице прогресса (declension/conjugation/vocabulary), связывая изолированные квесты с реальным текстом.

## Вне рамок

- Автоматическая оценка качества свободного перевода (NLP-сравнение смысла) — вне рамок первой версии, самооценка учеником достаточна для MVP.
