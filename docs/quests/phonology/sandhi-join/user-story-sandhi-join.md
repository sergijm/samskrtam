# US-PHON-02 — Сборка слитной формы из отдельных слов (обратное сандхи)

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `SANDHI_JOIN` (план)
> Связанные файлы: [quest-catalog.md §3.1](../../../services/quest-catalog.md)

## История

Как ученик, желающий писать связный санскритский текст, я хочу тренироваться соединять два отдельно данных слова в правильную слитную запись по правилам сандхи, чтобы уверенно составлять предложения, а не только разбирать чужие.

## Сценарий

1. Ученик открывает урок «Внешнее сандхи: сборка, гласные».
2. Система показывает два слова (`tatra` + `eva`) и просит ввести слитную форму.
3. Ученик вводит ответ (`tatraiva`); при ошибке показывается правильная форма и применённое правило.

## Критерии приёмки

- [ ] Тот же набор пар слов, что и в SANDHI_SPLIT для этого подтипа — оба типа переиспользуют один и тот же контент, только направление задания разное.
- [ ] Прогресс SANDHI_JOIN не смешивается с прогрессом SANDHI_SPLIT для той же пары (разные навыки — разбор vs сборка).
- [ ] Дистракторы для SINGLE_CHOICE — типичные ошибочные слияния (неверное применённое правило).

## Вне рамок

- Сборка цепочки из более чем двух слов подряд — отдельная будущая история.
