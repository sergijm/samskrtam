# US-PHON-01 — Разбор внешнего сандхи в связном тексте

> Домен: Phonology · Тип: `SANDHI_SPLIT` (частично реализован, см. [curriculum-service/eamenau.md](../../../services/curriculum-service/eamenau.md))
> Связанные файлы: [quest-catalog.md §3.1](../../../services/quest-catalog.md#31-sandhi_split--sandhi_join--частично-реализован)

## История

Как ученик, читающий связные санскритские тексты, я хочу тренироваться разбирать слитно
написанные слова на стыке (внешнее сандхи) на исходные компоненты, чтобы уверенно членить
незнакомые предложения на отдельные слова при чтении.

## Сценарий

1. Ученик открывает урок «Внешнее сандхи: гласные» (материал — учебник Eméneau, см. `eamenau.md`).
2. Система показывает слитную запись (`tatraiva`) и просит ввести разбор на компоненты (`tatra` + `eva`).
3. Ученик вводит разбор свободным текстом (два слова через пробел или разделитель).
4. Система сверяет разбор с эталонным (`components[]` из payload), при ошибке показывает верный разбор и номер применённого правила сандхи (из справочника Eméneau, 1–71).
5. Прогресс по единице (конкретная пара «поверхностная форма → правило») обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Задание всегда показывает правило сандхи (номер + краткая формулировка) после ответа — независимо от того, верный он или нет, чтобы разбор был осмысленным, а не угадыванием.
- [ ] Дистракторы для режима SINGLE_CHOICE — типичные ошибочные разборы (неверная граница слов, неверное применённое правило), а не случайные слова.
- [ ] Урок группирует задания по подтипу сандхи (гласные/согласные/висарга — см. `eamenau.md`), пользователь может выбрать конкретный подтип для тренировки как отдельный Quest.
- [ ] Прогресс по внешнему сандхи не смешивается с прогрессом по внутреннему сандхи (SANDHI_SPLIT для морфофонемных изменений при словообразовании) — это разные Quest, даже если использован общий тип.

## Вне рамок

- Обратная операция (SANDHI_JOIN — собрать слитную форму из компонентов) — отдельная будущая история.
- Автоматическая сегментация целого предложения на слова (полноценный sandhi-splitter) — не в этой истории, здесь только задание на одну известную пару.
