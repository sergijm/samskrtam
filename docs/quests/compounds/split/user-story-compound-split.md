# US-COMP-01 — Разбор сложного слова на члены

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `COMPOUND_SPLIT` (план)
> Связанные файлы: [quest-catalog.md §7.1](../../../services/quest-catalog.md)

## История

Как ученик, столкнувшийся со сложными словами (samāsa) при чтении, я хочу тренироваться разбирать сложное слово на составляющие его члены, чтобы понимать смысл длинных композитов, характерных для санскритской прозы и поэзии.

## Сценарий

1. Ученик открывает урок «Разбор сложных слов: базовый набор».
2. Система показывает сложное слово (`rājaputraḥ`) и просит ввести/выбрать разбор на члены (`rāja` + `putra`).
3. Ученик отвечает; при ошибке показывается верный разбор с переводом каждого члена.

## Критерии приёмки

- [ ] Первая версия — только двучленные композиты; трёх- и более членные — отдельная будущая история с более сложной моделью payload.
- [ ] Дистракторы (SINGLE_CHOICE) — правдоподобные, но неверные разборы того же слова (неверная граница между членами).
- [ ] Единица прогресса — конкретное сложное слово, не тип самасы (тип определяется отдельным заданием COMPOUND_TYPE).

## Вне рамок

- Определение типа самасы по разобранному слову — отдельный тип `COMPOUND_TYPE` (см. compounds/type/), не смешивается в одном вопросе.
