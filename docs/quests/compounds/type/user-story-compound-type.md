# US-COMP-02 — Определение типа сложного слова (самасы)

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `COMPOUND_TYPE` (план)
> Связанные файлы: [quest-catalog.md §7.1](../../../services/quest-catalog.md)

## История

Как ученик, уже умеющий разбирать сложное слово на члены, я хочу определять тип самасы (tatpuruṣa/dvandva/bahuvrīhi/avyayībhāva/karmadhāraya) по уже разобранному слову, чтобы понимать, как именно связаны члены композита по смыслу — это меняет перевод целиком.

## Сценарий

1. Ученик открывает урок «Типы самасы».
2. Система показывает уже разобранное сложное слово с переводом членов (`rāja` + `putra` = «царь» + «сын») и просит выбрать тип самасы из 5 вариантов.
3. Ученик отвечает (tatpuruṣa — «сын царя»); при ошибке объясняется отличие от других типов на этом же примере (bahuvrīhi дало бы «тот, чей сын — царь»).

## Критерии приёмки

- [ ] Для каждого слова урока в объяснении явно показано, как менялся бы перевод при другом типе самасы — не просто «правильный ответ: tatpuruṣa», а сравнение.
- [ ] Единица прогресса отдельна от COMPOUND_SPLIT того же слова — разные навыки (разбор на части vs понимание смысловой связи).
- [ ] Дистракторы — все 5 типов самасы предлагаются как варианты в каждом вопросе (не подмножество), чтобы ученик учил полный набор, а не угадывал из уменьшенного списка.

## Вне рамок

- Составные многоступенчатые самасы (самаса внутри самасы) — отдельная будущая история.
