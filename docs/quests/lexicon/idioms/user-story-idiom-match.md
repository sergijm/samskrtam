# US-LEX-08 — Узнавание устойчивого выражения в тексте

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `IDIOM_MATCH` (план)
> Связанные файлы: [quest-catalog.md §5](../../../services/quest-catalog.md)

## История

Как ученик, читающий произведения из sangraha-service, я хочу узнавать устойчивые выражения и формулы (например, стандартные зачины строф, эпитеты богов), чтобы не переводить их буквально слово за словом и быстрее ориентироваться в знакомых по жанру формулах.

## Сценарий

1. Ученик открывает урок «Устойчивые выражения: эпитеты».
2. Система показывает выражение из текста (`kamalanayana`, «лотосоокий») и просит выбрать его устоявшийся смысл из вариантов.
3. Ученик отвечает; при ошибке — показывается буквальный разбор по частям и устоявшееся значение.

## Критерии приёмки

- [ ] Материал — только выражения, явно размеченные как идиоматические в content-service (отдельный признак, не выводится автоматически из текста).
- [ ] Дистракторы — правдоподобные, но неверные истолкования (буквальный, но неверный в контексте перевод).
- [ ] Урок растёт вместе с корпусом sangraha-service — новые идиомы добавляются без изменения типа/кода.

## Вне рамок

- Автоматическое выявление идиом в новом тексте — вне рамок, разметка ручная/полуручная.
