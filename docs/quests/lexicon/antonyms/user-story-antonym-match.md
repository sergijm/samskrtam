# US-LEX-05 — Подбор антонима к слову

> Домен: см. [quest-catalog.md](../../../services/curriculum-service/quest-catalog.md) · Тип: `VOCABULARY_ANTONYM` (план)
> Связанные файлы: [quest-catalog.md §5](../../../services/curriculum-service/quest-catalog.md)

## История

Как ученик, я хочу тренироваться подбирать антоним к знакомому слову (например, `mahat` «большой» → `alpa` «малый»), чтобы лучше запоминать пары противоположных понятий, часто встречающихся вместе в текстах.

## Сценарий

1. Ученик открывает урок «Антонимы: качества».
2. Система показывает слово (`uccaḥ`, «высокий») и просит выбрать антоним из вариантов.
3. Ученик выбирает ответ; при ошибке показывается верная пара с переводом обоих слов.

## Критерии приёмки

- [ ] Антонимические пары хранятся как отдельная сущность в curriculum-service, аналогично `synonymGroupId` (см. `quest-item-model.md`), не как одностороннее поле у слова.
- [ ] Дистракторы — слова той же части речи и тематики, но не образующие с исходным словом антонимической пары.
- [ ] Прогресс по VOCABULARY_ANTONYM не смешивается с VOCABULARY_SYNONYM того же слова.

## Вне рамок

- Автоматический подбор антонимических пар по корпусу — пары задаются вручную при наполнении curriculum-service.
