# US-LEX-01 — Подбор синонима из группы близких по значению слов

> Домен: Lexicon · Тип: `VOCABULARY_SYNONYM` (план)
> Связанные файлы: [quest-catalog.md §5](../../../services/curriculum-service/quest-catalog.md#5-лексика)

## История

Как ученик с базовым словарным запасом, я хочу тренироваться подбирать синонимы к
известному слову из группы близких по значению санскритских слов (например, для «слон» —
gaja, hastin, dvipa, kariṇ), чтобы расширять активный словарь и лучше понимать
художественные тексты, где один и тот же предмет часто называется разными словами по
метру или стилю.

## Сценарий

1. Ученик открывает урок «Синонимы: животные» (тематическая категория, см. `VocabularyCategory`).
2. Система показывает слово (`gajaḥ`, «слон») и просит выбрать его синоним из четырёх вариантов.
3. Варианты: один верный синоним из той же `synonymGroupId` (`hastī`) и три дистрактора — слова из **других** синонимических групп той же тематической категории «животные» (например, `aśvaḥ` «конь», `siṃhaḥ` «лев»), чтобы дистракторы были правдоподобны по теме, но однозначно неверны по значению.
4. Ученик выбирает ответ; при ошибке система показывает всю синонимическую группу целиком с переводом.
5. Прогресс по единице (слово + `synonymGroupId`) обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Синонимическая группа хранится как отдельная сущность в curriculum-service (`synonymGroupId`), не как атрибут одного слова — один и тот же `VocabularyWord` может входить только в одну группу синонимов на эту версию задания.
- [ ] Дистракторы выбираются из той же тематической категории (`VocabularyCategory`), но из **других** групп синонимов — не из случайного словаря, иначе задание превращается в проверку общей эрудиции, а не именно синонимии.
- [ ] Если у слова в группе меньше 4 участников для формирования дистракторов внутри темы — генератор берёт дистракторы из соседних тематических категорий, явно помечая это в данных (чтобы UI мог, при желании, визуально отличать «внутритематические» дистракторы от «внешних»).
- [ ] Прогресс по `VOCABULARY_SYNONYM` не смешивается с прогрессом по `VOCABULARY_WORD` для того же слова — это разные `itemId`, разные навыки (перевод слова vs узнавание синонима).

## Вне рамок

- Автоматическое построение синонимических групп из корпуса — группы формируются вручную/полу-вручную на этапе наполнения curriculum-service, не входит в эту историю.
- Антонимы (`VOCABULARY_ANTONYM`) — отдельная будущая история.
