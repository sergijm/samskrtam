# US-LEX-04 — Определение тематической категории слова

> Домен: Lexicon · Тип: `VOCABULARY_SEMANTIC_FIELD` (план)
> Связанные файлы: [quest-catalog.md §5](../../../services/curriculum-service/quest-catalog.md#5-лексика)

## История

Как ученик, начинающий читать произведения из `sangraha-service`, я хочу тренироваться
относить незнакомое или полузабытое слово к тематической категории (родство, природа,
война, ритуал), чтобы быстрее ориентироваться в незнакомом тексте по контексту, даже не
вспомнив точный перевод слова.

## Сценарий

1. Ученик открывает урок «Категории: родство vs природа vs война» (смешанный набор из нескольких категорий для тренировки различения).
2. Система показывает слово (`bhrātā`, «брат») и просит выбрать категорию из вариантов: «родство», «природа», «война», «ритуал».
3. Ученик выбирает ответ; при ошибке система показывает перевод слова и верную категорию.
4. Прогресс по единице (слово + категория) обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Категории берутся из уже существующего механизма `VocabularyCategory` (work→chapter, см. `architecture.md §3.5`) — не заводится параллельная классификация, используется то, что уже есть в curriculum-service.
- [ ] Слово может относиться только к одной категории в рамках одного QuestItem этого типа — если слово размечено в нескольких категориях (собрание сочинений, разные главы), для генерации берётся основная/первая, остальные не создают дублирующих QuestItem.
- [ ] Дистракторы — реально используемые категории, не выдуманные для конкретного задания — набор одинаков для всего урока, чтобы ученик учил устойчивый список тем, а не угадывал новые варианты каждый раз.
- [ ] Урок можно собрать из любого поднабора категорий (2–4 сразу) — конкретный набор категорий определяется при создании `Quest`, не жёстко зашит в тип.

## Вне рамок

- Автоматическая тематическая классификация новых слов при импорте текста — вне рамок, категории проставляются вручную/полуавтоматически при наполнении curriculum-service (см. `sangraha-service.md`).
