# US-LEX-07 — Образование производного слова по суффиксу (taddhita)

> Домен: см. [quest-catalog.md](../../../services/curriculum-service/quest-catalog.md) · Тип: `WORD_FORMATION` (план)
> Связанные файлы: [quest-catalog.md §5](../../../services/curriculum-service/quest-catalog.md)

## История

Как ученик, знающий базовый словарь, я хочу тренироваться образовывать производное слово от известного существительного с помощью типового суффикса (например, `-tva` — абстрактное существительное: `manuṣya` → `mānuṣatva`, «человечность»), чтобы расширять словарь через понимание словообразовательной модели, а не запоминание каждого слова отдельно.

## Сценарий

1. Ученик открывает урок «Словообразование: -tva (абстрактные существительные)».
2. Система показывает исходное слово (`manuṣyaḥ`) и просит образовать производное с суффиксом `-tva`.
3. Ученик вводит ответ (`mānuṣatvam`); при ошибке — показывается правило (гуна/вриддхи первого слога основы + суффикс).

## Критерии приёмки

- [ ] Один урок — один суффикс; смешение суффиксов — в отдельном Quest «повторение» на будущее, не в базовой версии.
- [ ] Единица прогресса — (исходное слово + суффикс), тип открыт для расширения новыми суффиксами без изменения кода — просто новый Quest с новым набором данных.

## Вне рамок

- Составные (многоступенчатые) производные — отдельная будущая история.
