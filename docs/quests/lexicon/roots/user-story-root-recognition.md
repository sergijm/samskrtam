# US-LEX-03 — Определение корня, от которого образовано слово

> Домен: Lexicon · Тип: `VOCABULARY_ROOT` (план)
> Связанные файлы: [quest-catalog.md §5](../../../services/curriculum-service/quest-catalog.md#5-лексика)

## История

Как ученик среднего уровня, я хочу тренироваться определять глагольный корень (dhātu),
от которого образовано знакомое существительное или прилагательное, чтобы видеть связи
между словами и быстрее угадывать значение новых, но однокоренных слов при чтении.

## Сценарий

1. Ученик открывает урок «Корни: движение» (тематическая подборка производных слов от корней движения).
2. Система показывает производное слово (`gatiḥ`, «движение, путь») и просит выбрать корень, от которого оно образовано, из вариантов.
3. Варианты — 3–4 корня той же тематической группы (`√gam`, `√i`, `√car`, `√yā`), один из них верный.
4. Ученик выбирает ответ; при ошибке показывается словообразовательная модель (`√gam` + суффикс `-ti` → `gati-`).
5. Прогресс по единице (слово + корень) обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Дистракторы — корни той же смысловой группы (все «про движение»), а не случайные — иначе задание сводится к угадыванию темы, а не к знанию конкретной словообразовательной связи.
- [ ] Урок работает только со словами, для которых в curriculum-service явно указана производящая основа (`rootIast`) — слова без установленной этимологии в выборку не попадают, ошибочные догадки не публикуются как факт.
- [ ] Показ словообразовательной модели после ответа — не просто корень, а конкретный суффикс/паттерн, чтобы задание учило закономерности, а не отдельным парам слово-корень.

## Вне рамок

- Обратное направление (по корню перечислить все известные производные) — годится как отдельный тип упражнения на будущее, не в этой истории.
- Автоматический морфологический анализ незнакомых слов — вне рамок, здесь корень задан заранее вручную в curriculum-service.
