# US-LEX-06 — Определение рода существительного по форме

> Домен: см. [quest-catalog.md](../../../services/curriculum-service/quest-catalog.md) · Тип: `VOCABULARY_GENDER` (план)
> Связанные файлы: [quest-catalog.md §5](../../../services/curriculum-service/quest-catalog.md)

## История

Как ученик среднего уровня, я хочу тренироваться определять род существительного по его словарной форме, включая неочевидные случаи (например, `nadī` женского рода при внешнем сходстве с другими типами основ), чтобы не ошибаться в согласовании прилагательных при чтении и письме.

## Сценарий

1. Ученик открывает урок «Род: неочевидные случаи».
2. Система показывает слово в словарной форме (`matiḥ`, «мысль») и просит выбрать род из трёх вариантов.
3. Ученик отвечает; при ошибке показывается перевод и краткое объяснение, почему род именно такой (тип основы, исключение из общего правила).

## Критерии приёмки

- [ ] Урок включает только слова с реально неочевидным родом (расхождение между обликом слова и ожидаемым по типу основы родом) — отбор вручную в curriculum-service, не автоматический по всему словарю.
- [ ] Единица прогресса — само слово; не связана с прогрессом DECLENSION_FORM того же слова (разные навыки).

## Вне рамок

- Слова с очевидным родом (стандартные a-основы м.р., ā-основы ж.р.) — не включаются в этот тип, они уже покрыты обычным изучением словаря.
