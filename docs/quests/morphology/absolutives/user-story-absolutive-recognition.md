# US-MORPH-04 — Узнавание и перевод деепричастий (ktvā/lyap)

> Домен: Morphology · Тип: `ABSOLUTIVE_FORM` (план)
> Связанные файлы: [quest-catalog.md §2.5](../../../services/curriculum-service/quest-catalog.md#25-absolutive_form-деепричастие--план)

## История

Как ученик, читающий связные тексты, я хочу узнавать деепричастие (несклоняемую форму
глагола на `-tvā` или `-ya`) и правильно переводить его как «сделав X», чтобы понимать
цепочки последовательных действий в предложении — самую частую конструкцию вместо
«и сделал X, и сделал Y» в санскритской прозе.

## Сценарий

1. Ученик открывает урок «Деепричастия: простые глаголы без приставки».
2. Система показывает форму (`gatvā`) и просит выбрать/ввести перевод («придя», «сходив»).
3. Ученик отвечает (SINGLE_CHOICE из вариантов перевода или FREE_TEXT).
4. Система проверяет ответ, при ошибке показывает исходный корень (`√gam`) и правило выбора суффикса (`-tvā` для глаголов без приставки, `-ya`/`-tya` — с приставкой, см. `quest-catalog.md §2.5`).
5. Прогресс по единице (корень + форма) обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Первая версия — только глаголы без приставки (`-tvā`); формы с приставкой (`-ya`) — отдельный урок в той же подпапке, отдельный `Quest`, без изменения типа.
- [ ] Задание не требует склонения — деепричастие несклоняемо, единица прогресса не содержит падеж/число/род (в отличие от declension/participle).
- [ ] Дистракторы для SINGLE_CHOICE — переводы деепричастий других корней, схожих по звучанию или значению, не случайные слова.
- [ ] На странице урока показывается таблица «глагол → его деепричастие» для справки, независимо от статуса прогресса по конкретной единице.

## Вне рамок

- Инфинитив (`tumun`) — отдельный будущий тип `INFINITIVE_FORM`, не смешивается с деепричастием, хотя оба несклоняемы.
- Разбор деепричастных оборотов в целом предложении — относится к синтаксису (`PARTICIPLE_CLAUSE`).
