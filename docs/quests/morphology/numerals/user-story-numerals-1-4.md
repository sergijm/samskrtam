# US-MORPH-05 — Склонение числительных 1–4

> Домен: Morphology · Тип: `NUMERAL_FORM` (план)
> Связанные файлы: [quest-catalog.md §2.2](../../../services/curriculum-service/quest-catalog.md#22-numeral_form--план)

## История

Как ученик, желающий уверенно называть количество предметов, я хочу тренировать
склонение числительных «один»–«четыре» (единственные числительные санскрита, различающие
падеж, число и род по полной парадигме, близкой к местоименной), чтобы правильно
согласовывать их с существительным в тексте.

## Сценарий

1. Ученик открывает урок «Числительные 1–4: склонение».
2. Система показывает числительное (`dvi-`, «два») и требуемую форму (instrumental, женский род).
3. Ученик вводит форму (`dvābhyām`).
4. Система проверяет ответ; при ошибке показывает верную форму и отмечает нерегулярность (у `dvi-` нет единственного числа — это отдельно объясняется на странице урока, а не в каждом вопросе).
5. Прогресс по единице (числительное + падеж + число + род) обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Урок явно разделён по числительным: `eka-` (1, склоняется как местоимение, только ед.ч.), `dvi-` (2, только дв.ч.), `tri-`/`catur-` (3–4, только мн.ч., различают род) — три подурока (`Quest`) внутри этой подпапки, не один смешанный.
- [ ] Дистракторы — формы того же числительного в других падежах, не формы других числительных (чтобы не путать «не то число» с «не тот падеж»).
- [ ] На LessonPage — краткая справка о нерегулярности парадигмы (нет полного набора чисел, в отличие от обычных существительных).

## Вне рамок

- Числительные 5–19 (не различают род, не изменяются по числам, только по падежу) и 20+ (склоняются как a-основы ср. рода) — отдельные будущие истории, у каждой группы своя, отличная от 1–4, парадигма.
