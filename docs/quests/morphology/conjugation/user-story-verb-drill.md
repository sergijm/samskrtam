# US-MORPH-02 — Тренировка личных форм глагола (laṭ-lakāra)

> Домен: Morphology · Тип: `CONJUGATION_FORM` (план)
> Связанные файлы: [quest-catalog.md §2.3](../../../services/quest-catalog.md#23-conjugation_form--план) · [quest-item-model.md §2](../../../services/quest-item-model.md#2-content-service--генерация-smselflearnsamskrtamcontentquest)

## История

Как ученик, освоивший базовые склонения, я хочу практиковать спряжение глаголов I класса
(bhū-gaṇa) в настоящем времени (laṭ-lakāra) по лицу и числу, чтобы уверенно образовывать
личные формы глаголов при чтении и составлении простых предложений.

## Сценарий

1. Ученик открывает урок «Настоящее время, I класс глаголов».
2. Система показывает корень (`√bhū`, «быть/становиться») и требуемую форму (3-е лицо, единственное число, parasmaipada).
3. Ученик вводит форму (`bhavati`).
4. Система проверяет ответ; при ошибке показывает правильную форму и краткое объяснение (какой суффикс/гуна использованы).
5. Прогресс по единице (корень + lakāra + лицо + число + pada) обновляется тем же алгоритмом повторения, что и для declension — без специальной логики для этого типа.

## Критерии приёмки

- [ ] Единица прогресса — комбинация (dhatu, lakara, purusha, vacana, pada), отдельная от declension-прогресса того же пользователя (см. [quest-item-model.md §4](../../../services/quest-item-model.md#4-quiz-service--прохождение-и-прогресс-smselflearnsamskrtamquizprogress) — прогресс типо-агностичен, но `itemId` уникален на комбинацию).
- [ ] Первая версия урока покрывает только parasmaipada, только I класс, только laṭ и loṭ (см. [quest-catalog.md §2.3](../../../services/quest-catalog.md#23-conjugation_form--план)) — ātmanepada и остальные lakāra не входят в эту историю.
- [ ] Дистракторы (если задание — выбор варианта) — формы того же корня в других лицах/числах, а не случайные слова, чтобы тренировать именно узнавание окончания, а не значения корня.
- [ ] Статус урока на LessonPage считается по тем же правилам NEW/LEARNING/DUE/MASTERED, что и для declension.

## Вне рамок

- Неправильные (irregular) глаголы — отдельная будущая история.
- Ātmanepada-формы — отдельная будущая история после освоения parasmaipada.
