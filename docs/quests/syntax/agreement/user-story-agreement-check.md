# US-SYNT-02 — Проверка согласования прилагательного с существительным

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `AGREEMENT_CHECK` (план)
> Связанные файлы: [quest-types-overview.md, тип №14](../../../services/quest-types-overview.md)

## История

Как ученик, я хочу тренироваться выбирать правильную форму прилагательного, согласованную с данным существительным по роду, числу и падежу, чтобы не путать окончания при построении собственных фраз.

## Сценарий

1. Ученик открывает урок «Согласование: прилагательное + существительное».
2. Система показывает существительное в конкретной форме (`vane`, locative sg., средний род) и прилагательное в базовой форме (`sundara-`, «красивый»).
3. Ученику предлагается выбрать/ввести согласованную форму прилагательного (`sundare`) из вариантов с разными падежом/числом/родом.

## Критерии приёмки

- [ ] Дистракторы — формы прилагательного, совпадающие по 2 из 3 признаков (падеж верный, род неверный и т.п.) — тренирует именно внимательность к согласованию, а не угадывание.
- [ ] Единица прогресса — пара (падеж, число, род) в целом, а не конкретная пара слов — правильный ответ должен обобщаться на любую подходящую пару существительное+прилагательное.
- [ ] Урок требует, чтобы ученик уже прошёл DECLENSION_FORM для соответствующего типа основы — мягкая зависимость на уровне контента.

## Вне рамок

- Согласование глагола с подлежащим по лицу/числу — отдельная будущая история, другой набор правил.
