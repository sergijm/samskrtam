# US-SYNT-03 — Корреляты yad…tad в сложном предложении

> Домен: см. [quest-catalog.md](../../../services/quest-catalog.md) · Тип: `RELATIVE_CLAUSE` (план)
> Связанные файлы: [quest-types-overview.md, тип №15](../../../services/quest-types-overview.md)

## История

Как ученик, читающий более сложные предложения, я хочу тренировать понимание конструкции «yad… tad…» («который… тот…»), чтобы правильно связывать относительное и главное предложение при чтении и переводе.

## Сценарий

1. Ученик открывает урок «Относительные конструкции: yad-tad».
2. Система показывает предложение с пропущенным коррелятом (`___ naraḥ dharmaṃ carati, saḥ sukhī bhavati`) и просит выбрать правильное слово (`yaḥ`).
3. Ученик отвечает; при ошибке — объясняется согласование yad/tad по роду/числу/падежу с соответствующим существительным в каждой из двух частей.

## Критерии приёмки

- [ ] Первая версия — только конструкция «yad… tad…» с существительным-подлежащим; другие схемы (yad как обстоятельство, yatra/tatra и т.п.) — отдельные будущие Quest в этой же подпапке.
- [ ] Дистракторы — формы yad/tad в неверном роде/числе/падеже относительно контекста предложения.

## Вне рамок

- Корреляты для места/времени/образа действия (yatra-tatra, yadā-tadā, yathā-tathā) — отдельные будущие истории с той же структурой урока.
