# US-SYNT-04 — Причастный оборот вместо придаточного предложения

> Домен: см. [quest-catalog.md](../../../services/curriculum-service/quest-catalog.md) · Тип: `PARTICIPLE_CLAUSE` (план)
> Связанные файлы: [quest-types-overview.md, тип №16](../../../services/quest-types-overview.md)

## История

Как ученик, читающий прозу sangraha-service, я хочу тренироваться понимать причастный/деепричастный оборот как эквивалент придаточного предложения («тот, кто пришёл» = причастие вместо «который пришёл»), чтобы не спотыкаться на самой частой синтаксической конструкции санскритской прозы.

## Сценарий

1. Ученик открывает урок «Причастный оборот вместо придаточного».
2. Система показывает предложение с причастным оборотом из реального текста (sangraha-service) и просит выбрать эквивалентную перифразу с придаточным предложением из вариантов.
3. Ученик отвечает; при ошибке — показывается разбор оборота по словам.

## Критерии приёмки

- [ ] Материал берётся только из проанализированных стихов/фрагментов sangraha-service (`status=ANALYZED`), не придумывается вручную для урока.
- [ ] Урок явно требует, чтобы соответствующее причастие (PARTICIPLE_FORM) уже было пройдено — мягкая зависимость по контенту.
- [ ] Дистракторы — правдоподобные, но неверные по смыслу перифразы (перепутанный субъект действия, неверное время).

## Вне рамок
