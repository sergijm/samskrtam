# US-SYNT-01 — Выбор падежа по семантической роли (kāraka)

> Домен: Syntax · Тип: `KARAKA_CASE_CHOICE` (план)
> Связанные файлы: [quest-catalog.md §4.1](../../../services/quest-catalog.md#41-karaka_case_choice--план)

## История

Как ученик, освоивший отдельные падежные формы, я хочу тренироваться выбирать правильный
падеж для слова в предложении по его смысловой роли при конкретном глаголе (кто действует,
над кем/чем совершается действие, кому адресовано и т.д.), чтобы понимать, почему в
санскритском предложении используется именно этот падеж, а не запоминать формы изолированно.

## Сценарий

1. Ученик открывает урок «Kāraka: инструмент действия (karaṇa)».
2. Система показывает предложение с глаголом и одним словом, выделенным в базовой форме (лемме), без падежного оформления (`rāma` + `likhati` + `lekhanī`, «Рама пишет — [чем?] — перо»).
3. Ученику предлагается выбрать правильный падеж выделенного слова из вариантов (SINGLE_CHOICE: instrumental, dative, ablative, locative).
4. Система проверяет выбор; при ошибке объясняет роль (karaṇa → instrumental, «инструмент действия оформляется творительным падежом») и показывает верную словоформу целиком (`lekhanyā`).
5. Прогресс по единице (глагол + роль + целевое слово) обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Урок посвящён одной роли kāraka за раз (в этой истории — karaṇa); смешение ролей в одном Quest — предмет отдельной будущей истории «повторение всех ролей».
- [ ] Дистракторы — падежи, которые правдоподобно спутать с целевым (для karaṇa — dative и ablative, которые тоже выражают «средство/источник» в отдельных контекстах), а не произвольный набор из восьми падежей.
- [ ] После ответа показывается объяснение роли на русском и английском (см. i18n-конвенции), а не только верная форма.
- [ ] QuestItem работает с целым предложением как `prompt` — не требует изменения модели `QuestItem`/`QuestItemPayload` (см. [quest-item-model.md §1](../../../services/quest-item-model.md#1-общая-модель-shared-samskrtam-dtos-smselflearnsamskrtamquest)).

## Вне рамок

- Пассивные конструкции (где kartā оформляется instrumental, а не nominative) — отдельная будущая история, требует отдельного набора предложений.
- Свободный ввод падежной формы вместо выбора роли — рассматривается после того, как выбор роли отработан.
