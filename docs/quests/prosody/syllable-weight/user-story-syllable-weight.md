# US-PROS-02 — Разметка долготы слогов (laghu/guru) в строке

> Домен: см. [quest-catalog.md](../../../services/curriculum-service/quest-catalog.md) · Тип: `SYLLABLE_WEIGHT` (план)
> Связанные файлы: [quest-types-overview.md, тип №26](../../../services/quest-types-overview.md)

## История

Как ученик, готовящийся к полноценному различению стихотворных размеров, я хочу тренироваться размечать каждый слог строки как краткий (laghu) или долгий (guru) по стандартным правилам, чтобы затем самостоятельно определять размер по получившейся схеме.

## Сценарий

1. Ученик открывает урок «Долгота слогов: базовые правила».
2. Система показывает строку, разбитую на слоги, и просит для каждого слога выбрать laghu/guru (MULTI_SELECT/последовательный выбор по слогам).
3. Ученик отвечает; при ошибке подсвечиваются неверно размеченные слоги с указанием правила (краткий гласный + не перед сочетанием согласных → laghu; долгий гласный, гласный перед сочетанием согласных, или в конце строки → guru).

## Критерии приёмки

- [ ] Единица прогресса — на уровне отдельного слога в конкретной строке, не всей строки целиком — частичный прогресс возможен.
- [ ] Правила разметки применяются программно (детерминированный алгоритм по гласному и следующим согласным), не хранятся вручную построчно.
- [ ] Урок явно позиционируется как предпосылка для CHANDAS_IDENTIFICATION (полной схемы) — ссылка на связь в описании урока.

## Вне рамок

- Определение конкретного названия размера по получившейся схеме долгот — это уже задача полной версии CHANDAS_IDENTIFICATION, не этого типа.
