# US-PROS-01 — Различение шлоки (śloka) от других размеров по счёту слогов

> Домен: Prosody · Тип: `CHANDAS_IDENTIFICATION` (план, первая итерация)
> Связанные файлы: [quest-catalog.md §6.1](../../../services/curriculum-service/quest-catalog.md#61-chandas_identification--план)

## История

Как ученик, начавший читать стихотворные тексты (см. `sangraha-service`), я хочу
тренироваться узнавать самый частый размер — śloka (anuṣṭubh), — по числу слогов в
четверти строки (pāda), чтобы отличать его от других размеров и не путать границы строк
при чтении стихотворного текста, где перенос строки не совпадает с синтаксической паузой.

## Сценарий

1. Ученик открывает урок «Размер: śloka или нет?».
2. Система показывает одну четверть стиха (pāda) из текста sangraha-service.
3. Ученик отвечает SINGLE_CHOICE: «śloka» или «другой размер» (упрощённая бинарная классификация для первой итерации).
4. Система проверяет ответ на основе предрассчитанного числа слогов (8 слогов на pāda — признак śloka в этой упрощённой версии; полная схема долгот — в следующей итерации, см. `quest-catalog.md §6.1`), показывает разбиение строки на слоги.
5. Прогресс по единице (конкретная pāda + правильный ответ) обновляется общим алгоритмом повторения.

## Критерии приёмки

- [ ] Сегментация строки на слоги и подсчёт их числа выполняется backend-генератором автоматически по тексту — не хранится вручную как отдельное поле в БД (см. `quest-catalog.md §6.1` — единственный тип, где `prompt` строится алгоритмически).
- [ ] Первая итерация — только бинарный признак «8 слогов = вероятно śloka / не 8 = не śloka», без полной схемы долгот (laghu/guru) и без различения остальных классических размеров.
- [ ] После ответа строка показывается с визуальной разбивкой на слоги (не просто число), чтобы ученик видел, как считать самостоятельно.
- [ ] Источник строк — только стихи из `sangraha-service` с уже подтверждённым (`status=ANALYZED`) анализом, не произвольный ввод.

## Вне рамок

- Полная схема долгот (laghu/guru) и различение остальных классических размеров (triṣṭubh, indravajrā и т.д.) — отдельная будущая история, требует типа `SYLLABLE_WEIGHT` как предпосылки (см. `quest-types-overview.md`, тип №26).
