# ADR-001 — Микросервисы вместо монолита

> Status: **Accepted** · Date: 2025

## Контекст
Учебный проект для изучения санскрита небольшой группой. Основная цель — освоение SDD и микросервисной архитектуры на практике.

## Решение
Микросервисная архитектура с отдельным сервисом на каждый тип квиза.

## Обоснование
- Учебная цель: практика микросервисов, Kafka, API Gateway, Contract-First SDD
- Каждый квиз имеет свою специфику — разная схема вопросов и логика проверки
- Статистика через очередь — классический микросервисный паттерн
- Dictionary с Cache-aside — отдельная зона ответственности

## Последствия
**Плюсы:** независимое развёртывание, изоляция БД, масштабируемость паттерна.
**Минусы:** сложнее локальная разработка, нужна инфраструктура (Kafka, Gateway, Keycloak).
