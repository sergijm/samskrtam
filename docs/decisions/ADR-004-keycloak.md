# ADR-004 — Keycloak вместо самописного Auth Service

> Status: **Accepted** · Date: 2025

## Контекст
Нужна аутентификация через несколько провайдеров: собственный аккаунт, Google, Mail.ru.

## Решение
Self-hosted Keycloak. Самописный Auth Service не создаётся.

## Обоснование
- Google — встроенный провайдер в Keycloak
- Mail.ru — добавляется как Generic OIDC Provider
- Все сервисы получают единый JWT вне зависимости от способа входа
- Конфигурация как код: `realm-export.json` в репозитории

## Последствия
**Плюсы:** нет самописной аутентификации, все провайдеры через один интерфейс.
**Минусы:** Mail.ru OIDC нестандартный, требует ручной настройки.
