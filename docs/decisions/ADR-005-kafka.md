# ADR-005 — Kafka для событий статистики

> Status: **Accepted** · Date: 2025

## Контекст
После каждого ответа нужно обновить статистику. Синхронный вызов блокировал бы ответ пользователю.

## Решение
Quiz сервисы публикуют события в Kafka. Statistics Service подписывается асинхронно.

## Топики
| Топик | Ключ | Retention |
|---|---|---|
| quiz.answer.submitted | userId | 7 дней |
| quiz.session.completed | userId | 7 дней |

Ключ = userId гарантирует порядок событий одного пользователя.

## Shared модуль
`shared/kafka-events` (Java 21) — единый источник истины для producer и consumer.

## Последствия
**Плюсы:** слабая связность, события не теряются при недоступности потребителя.
**Минусы:** eventual consistency — статистика обновляется с небольшой задержкой.
