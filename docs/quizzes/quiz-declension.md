# Спецификация квиза: Склонение санскритских существительных

> Связанные файлы: [README.md](../../README.md) · [services/quiz-service.md](../../services/quiz-service.md)
> Статус: **ЧЕРНОВИК**

---

## 1. Данные для квиза

### 1.1. Источник существительных
Существительные (основы) и их полные таблицы склонений загружаются в базу данных вручную. Для каждого существительного должны быть явно указаны его основа, тип тематической гласной и все 24 словоформы (8 падежей × 3 числа) в IAST.

**Пример исходных данных:**

```
agni- (i-основа) — огонь
agāra- (a-основа) — покои
aṅga- (a-основа) — член, часть
dhenu- (u-основа) — корова
nadī- (ī-основа) — река
pitṛ- (ṛ-основа) — отец
mālā- (ā-основа) — гирлянда
```

### 1.2. Категоризация основ
Каждое существительное относится к одному из типов тематической гласной:
*   `-a` (мужской/средний род)
*   `-ā` (женский род)
*   `-i` (мужской/женский род)
*   `-ī` (женский род)
*   `-u` (мужской/женский род)
*   `-ū` (женский род)
*   `-ṛ` (мужской/женский род)

### 1.3. Таблицы склонений
Для каждого существительного в БД хранится полная таблица склонения: 8 падежей × 3 числа = 24 словоформы. Все словоформы в IAST.

*   **Падежи (Vibhakti):**
    1.  Именительный (Nominative)
    2.  Винительный (Accusative)
    3.  Творительный (Instrumental)
    4.  Дательный (Dative)
    5.  Отложительный (Ablative)
    6.  Родительный (Genitive)
    7.  Местный (Locative)
    8.  Звательный (Vocative)
*   **Числа (Vacana):**
    1.  Единственное (Singular)
    2.  Двойственное (Dual)
    3.  Множественное (Plural)

## 2. Структура квиза

### 2.1. Типы квизов
Будет создано 8 отдельных квизов:
*   **7 квизов по типам основ:** По одному квизу для каждого типа тематической гласной (`-a`, `-ā`, `-i`, `-ī`, `-u`, `-ū`, `-ṛ`). В каждом таком квизе используются только слова соответствующего типа основы.
*   **1 комбинированный квиз:** Слова всех типов основ.

### 2.2. Количество вопросов в сессии
Определяется полем `questions_per_session` квиза в content-service (по умолчанию 20). Применяется единообразно для всех типов квизов — см. [content-service.md](../services/content-service.md) раздел 4.

### 2.3. Выбор слов при старте сессии
При каждом запуске квиза quiz-service случайным образом выбирает набор существительных из пула квиза в количестве `questions_per_session`. Выбранный набор слов фиксируется в сессии и не меняется на протяжении всего прохождения — в том числе при навигации вперёд и назад по вопросам.

*   **Ограничение:** Если для квиза по типу основы доступно менее `questions_per_session` слов, используются все доступные слова.

### 2.4. Структура вопроса
Каждый вопрос строится по следующей схеме:

*   **Фиксированная основа:** В рамках одного вопроса используется одно конкретное существительное. Например, если выбрана основа `dhenu-`, все варианты ответа — формы `dhenu-`.
*   **Указание целевой формы:** В вопросе явно указывается падеж и число.
    *   **Пример:** "Основа: `dhenu-`, Падеж: Отложительный, Число: Единственное"
*   **Правильный ответ:** Одна полная словоформа (основа + окончание) в IAST.
    *   **Пример:** `dhenoḥ`
*   **Генерация дистракторов (quiz-service):** Три неправильных ответа выбираются динамически из остальных форм того же существительного. Гарантируется, что текстовое представление каждого дистрактора отличается от правильного ответа и друг от друга (омонимичные формы исключаются из пула дистракторов).
    *   **Пример:** для `dhenoḥ` (Отложительный, Ед.ч.) — если эта же форма является и Родительным Ед.ч., она исключается. Дистракторы: `dhenave` (Дат., Ед.ч.), `dhenum` (Вин., Ед.ч.), `dhenvā` (Тв., Ед.ч.).

*   **Формат отображения:**
    *   Все формы записываются в IAST.
    *   Краткая тематическая гласная в отображении основы **не удваивается** (писать `dhenu-`, а не `dhenuu-`).

### 2.5. Порядок вопросов
Вопросы в сессии перемешиваются случайным образом при старте и фиксируются — порядок не меняется при навигации вперёд/назад.

### 2.6. Навигация и прогресс
*   Пользователь может перемещаться между вопросами вперёд и назад в рамках одной сессии.
*   В верхней части страницы квиза отображается **прогресс-бар**, показывающий процент отвеченных вопросов от общего числа в сессии.

## 3. Решённые вопросы

*   **Можно ли изменить ответ на уже отвеченный вопрос при возврате к нему?** Нет, нельзя. После выбора ответа он фиксируется.
*   **Отображать ли правильный ответ сразу после ответа пользователя или только в конце сессии?** Правильный ответ отображается сразу после выбора ответа пользователем, перед переходом к следующему вопросу.
