# Спецификация квиза: Склонение санскритских существительных

> Связанные файлы: [README.md](../../README.md) · [services/quiz-service.md](../../services/quiz-service.md)
> Статус: **ЧЕРНОВИК**

---

## 1. Данные для квиза

### 1.1. Источник существительных
Исходный список существительных (основ) будет расширен. Для каждого существительного в списке должна быть явно указана его основа и тип тематической гласной.

**Пример исходных данных:**

```
agni- (i-основа) — огонь
agāra- (a-основа) — покои
aṅga- (a-основа) — член, часть
dhenu- (u-основа) — корова
nadī- (ī-основа) — река
pitṛ- (ṛ-основа) — отец
mālā- (ā-основа) — гирлянда
```

### 1.2. Категоризация основ
Для каждого существительного из полного списка необходимо определить тип его основы по тематической гласной:
*   `-a` (мужской/средний род)
*   `-ā` (женский род)
*   `-i` (мужской/женский род)
*   `-ī` (женский род)
*   `-u` (мужской/женский род)
*   `-ū` (женский род)
*   `-ṛ` (мужской/женский род)

### 1.3. Выбор существительных для квиза
Из полного списка существительных для каждого типа тематической гласной (`-a`, `-ā`, `-i`, `-ī`, `-u`, `-ū`, `-ṛ`) будет выбрано **три слова случайным образом**.
*   **Критерий разнообразия:** При выборе слов следует стремиться к максимальному смысловому (семантическому) разнообразию, чтобы избежать однотипных примеров.
*   **Ограничение:** Итого не более трёх слов на каждый тип основы. Если для какого-либо типа основ доступно менее трёх слов, будут использованы все доступные слова.

### 1.4. Генерация склонений
Для каждого выбранного существительного (основы) должна быть сгенерирована полная таблица склонения, включающая все 8 падежей и 3 числа:

*   **Падежи (Vibhakti):**
    1.  Именительный (Nominative)
    2.  Винительный (Accusative)
    3.  Творительный (Instrumental)
    4.  Дательный (Dative)
    5.  Отложительный (Ablative)
    6.  Родительный (Genitive)
    7.  Местный (Locative)
    8.  Звательный (Vocative)
*   **Числа (Vacana):**
    1.  Единственное (Singular)
    2.  Двойственное (Dual)
    3.  Множественное (Plural)

Таким образом, для каждого существительного будет 24 уникальные словоформы. Все словоформы должны быть представлены в системе транслитерации IAST.

### 2. Структура квиза

### 2.1. Типы квизов
Будет создано 8 отдельных квизов:
*   **7 квизов по типам основ:** По одному квизу для каждого типа тематической гласной (`-a`, `-ā`, `-i`, `-ī`, `-u`, `-ū`, `-ṛ`). В каждом таком квизе будут использоваться только слова, относящиеся к данному типу основы.
*   **1 комбинированный квиз:** В этом квизе будут представлены слова всех типов основ.

### 2.2. Структура вопроса
Каждый вопрос в квизе строится по следующей схеме:

*   **Фиксированная основа:** В рамках одного вопроса используется одно конкретное существительное (основа). Например, если выбрана основа `dhenu-`, все варианты ответа будут формами `dhenu-`.
*   **Указание целевой формы:** В вопросе явно указывается падеж и число, для которых требуется выбрать правильную словоформу.
    *   **Пример:** "Основа: `dhenu-`, Падеж: Отложительный, Число: Единственное"
*   **Правильный ответ:** Одна полная словоформа (основа + окончание) в IAST, соответствующая указанному падежу и числу.
    *   **Пример:** Для вопроса выше правильный ответ: `dhenoḥ`
*   **Неправильные ответы (дистракторы):** Три другие полные словоформы той же основы, которые:
    *   Не совпадают с правильным ответом.
    *   Могут быть формами другого падежа или числа.
    *   Должны быть выбраны таким образом, чтобы быть правдоподобными, но неверными вариантами (например, формы из соседних падежей, или формы другого числа).
    *   **Пример:** Для вопроса "Основа: `dhenu-`, Падеж: Отложительный, Число: Единственное" (правильный ответ `dhenoḥ`), неправильные ответы могут быть: `dhenave` (Дательный, Ед.ч.), `dhenum` (Винительный, Ед.ч.), `dhenvā` (Творительный, Ед.ч.).

*   **Формат отображения:**
    *   Все формы записываются в IAST.
    *   Шрифт: Arial (требование к отображению в UI).
    *   Краткая тематическая гласная в отображении основы **не удваивается** (писать `dhenu-`, а не `dhenuu-`).

### 2.3. Порядок вопросов
Вопросы в каждом квизе каждый раз при прохождении перемешиваются случайным образом.
