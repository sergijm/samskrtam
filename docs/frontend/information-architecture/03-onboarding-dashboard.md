## 4. Онбординг первого захода

Не тест — мягкий выбор без ощущения экзамена:

1. Регистрация (есть).
2. Самоописание одним кликом: *"я только начинаю"* / *"уже знаю немного"* /
   *"хочу продолжить с конкретного места"* — маршрутизация, не оценка.
3. Маленькая гарантированно приятная демонстрация вместо
   упражнения-барьера — интерактивный разбор слова देव (deva) по формам.
4. Для "хочу продолжить с конкретного места" — прямой выбор урока из
   обычного списка курикулума, без теста.
5. → обычный Dashboard, уже не пустой (streak=1, несколько освоенных форм
   после шага 3).

---

## 5. Dashboard

Целевая структура — командный центр, отвечающий на "что делать сейчас":

1. **"Продолжить"** (главный CTA сверху) — следующий урок по курикулуму
   или SRS-очередь на сегодня, прямой запуск.
2. **Streak / общий прогресс** — дни подряд, форм освоено всего.
3. **Слабые места** — 2–3 пары падежей/форм с низким `successRate`.
4. **Путь к чтению** — конкретная метрика по конкретному тексту ("72%
   лексики гл. 2 Гиты уже пройдено").
5. **Карта прогресса** (см. `04-progress-map.md`) — ссылка на
   полноэкранную диагностику, не встроена в дашборд целиком.
6. Категории-плитки — второстепенная навигация внизу.

Слева — дерево курикулума из `01-curriculum-vs-catalog.md` §2 как
постоянное боковое меню.
