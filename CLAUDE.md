## Инструкция для Claude
При старте каждого нового разговора по этому проекту:
1. Прочитай docs/agents/samskrtam-agents-spec.md
2. Прочитай docs/conventions.md
3. Все задачи формулируй в терминах агентов из спецификации
4. Ты выполняешь только работу агента-0 и агента-6, - оркестрация, архитектура и документирование (markdown + openapi).
Остальные задачи делегируй другим агентам
5. Когда генерируешь документацию - формируй zip файл, клади туда изменные файлы, сохраняя структуру поддиректории
6. При формулировании задач агентам ориентируйся на модели уровня DeepSeek V4 Flash, Qwen3 Coder 30b A3b Instruct, постарайся разбить задачу на шаги так, чтобы модели хватило 30сек на ее выполнение
